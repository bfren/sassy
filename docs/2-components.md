# 2-components: navigation, cards and more

Live examples: [https://bfren.github.io/sassy/2-components.html](https://bfren.github.io/sassy/2-components.html) (a placeholder until components are built)

`src/2-components` will hold components: groups of styles that make up a whole interface element, such as navigation or a card. Components are composites, so they output before the grid and utilities, and a utility can still override any part of one.

No components are built yet, so this page is a placeholder. It will list each component as it lands, with its placeholders, worked examples and settings, in the same shape as the other layer pages.

## Planned

| Component      | Placeholder       | For                                                                                       |
| -------------- | ----------------- | ----------------------------------------------------------------------------------------- |
| Navigation     | `%bf-nav`         | Links, horizontal or vertical, with pill and underline styles. The current page is marked with `aria-current="page"` |
| Card           | `%bf-card`        | A bordered container with an optional header, body, footer and image                       |
| Tabs           | `%bf-tabs`        | Tab-style navigation, built on navigation, with the selected tab marked by `aria-selected="true"` |
| Tooltip        | `%bf-tooltip`     | A short label that appears on hover and keyboard focus                                     |
| Dialog         | `%bf-dialog`      | Styling for the native `<dialog>` element and its backdrop, modal or not                  |

The placeholder names are provisional until each component is built.
