Sassy

A Sass framework built from placeholder selectors. You extend the utilities and components you need onto your own selectors, so your HTML stays clean and your CSS holds only the rules you use.

@use "sassy/src" as sassy

.card
    @extend %bf-p-3
    @extend %bf-p-5-md
    @extend %bf-rounded
    @extend %bf-shadow-1

.card-title
    @extend %bf-c-primary
    @extend %bf-font-weight-700

Each placeholder sets one thing, and has a version for each breakpoint, such as %bf-p-5-md. Sassy outputs them in a fixed order, so breakpoints override base styles and utilities override components, whichever order you extend them in.

The layers

Sassy is built in six layers, numbered in the order their CSS is output. Each page shows its layer working, with the Sass, HTML and CSS for every example.

  1. 0 Core Loading and configuring Sassy, palette colours, breakpoints, and making placeholders of your own.
  2. 1 Forms Labels, inputs, selects, checks, switches, input groups and floating labels, with validation.
  3. 2 Components Buttons, navigation, cards, tabs, tooltips and dialogs.
  4. 3 Grid A 12-column flex grid whose columns change width at each breakpoint.
  5. 4 Utilities Single-purpose placeholders for text, spacing, layout, colour, display, borders, corners and shadow.
  6. 5 Theme Eight named colours you can change for a site, a section or at runtime.

Test pages

Pages used to check Sassy in different browsers: utilities, form controls and theme colours.

Getting started

Add Sassy to your project and load it with @use "sassy/src" as sassy, or link dist/full.css to use every utility as a class. The README covers both, and the docs cover each layer in full.
