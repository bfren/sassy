Sassy

Compiled from sass/index.sass into css/index.css, which this page loads.

Sassy is a Sass utility framework built from placeholder selectors. You @extend the utilities you need onto your own selectors, so your markup stays semantic and your CSS contains only the rules you use.

Documentation

  • 0-core: loading and configuring Sassy, and the functions and mixins it provides
  • 1-forms: form controls, and validation
  • 2-components: navigation, cards and more (to come)
  • 3-grid: rows and columns
  • 4-utilities: text, layout, colour, display, border, corners and shadow
  • 5-theme: theme colours, and changing them at runtime
