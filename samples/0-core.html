Loading and configuring Sassy

The core layer, src/0-core, holds Sassy's settings, the make mixins that generate placeholders, and a few helpers for your own styles. The full reference is in docs/0-core.md.

Each demo on this page is styled by sass/0-core.sass, compiled to css/0-core.css. Under each demo are its Sass, the CSS that Sassy outputs for it, and its HTML.

Palette colours and transparency

colour() returns any palette colour, and with-alpha() makes any colour transparent - here 60%, so the stripes show through.

A label on a grey 900 background at 60% 
@use "sassy/src" as sassy

.tooltip
    background-color: sassy.with-alpha(sassy.colour("grey", 900), 0.6)
    border-radius: 0.375rem
    color: sassy.colour("grey", 50)
    display: inline-block
    padding: 0.5rem 0.75rem
<span class="tooltip">A label on a grey 900 background at 60%</span>

Your own breakpoint styles

up() wraps your own styles in a media query for a breakpoint, as Sass cannot @extend inside one.

Make the window narrower than 768px and the text shrinks.

This text is 1rem, and 1.5rem from md upwards.

.hero
    font-size: 1rem
    margin: 0

    @include sassy.up(md)
        font-size: 1.5rem
<p class="hero">This text is 1rem, and 1.5rem from md upwards.</p>

Different values at different breakpoints

up-prop() takes a property, then its value at each breakpoint you name.

The sidebar is full width at first, half from 576px, and a quarter from 992px.

Sidebar
.sidebar
    background-color: sassy.colour("grey", 200)
    padding: 0.75rem 1rem
    @include sassy.up-prop(width (sm: 50%, lg: 25%))
<div class="sidebar">Sidebar</div>

Your own placeholders, in Sassy's style

make-responsive() generates a placeholder for each value and breakpoint, and make-passes() outputs them in Sassy's order. This stack has a 0.25rem gap, and 0.5rem from md upwards.

One Two Three 
@include sassy.make-passes
    @include sassy.make-responsive("stack", (1: 0.25rem, 2: 0.5rem)) using ($value)
        display: flex
        flex-direction: column
        gap: $value

.menu
    @extend %bf-stack-1
    @extend %bf-stack-2-md

.menu-named
    @extend %#{sassy.make-name("stack", 2)}
<div class="menu">
    <span class="box">One</span>
    <span class="box">Two</span>
    <span class="box">Three</span>
</div>
