Form controls and validation

The forms layer, src/1-forms, styles labels, text inputs, selects, checks, switches, input groups, floating labels, range, file and colour inputs, and validation. The full reference is in docs/1-forms.md.

Each demo on this page is styled by sass/1-forms.sass, compiled to css/1-forms.css. Under each demo are its Sass, the CSS that Sassy outputs for it, and its HTML.

A labelled text field with help text

As it appears on your passport.
@use "sassy/src" as sassy

.field
    @extend %bf-mb-3

    label
        @extend %bf-form-label

    input
        @extend %bf-form-control

.field-text
    @extend %bf-form-text
<div class="field">
    <label for="name">Name</label>
    <input type="text" id="name" placeholder="Your full name" />
    <div class="field-text">As it appears on your passport.</div>
</div>

Small and large controls

A size only changes custom properties, so extend it as well as the control.

.sizes
    @extend %bf-d-grid
    @extend %bf-gap-3

    input
        @extend %bf-form-control

    select
        @extend %bf-form-select

    .small
        @extend %bf-form-control-small

    .large
        @extend %bf-form-control-large
<div class="sizes">
    <input type="text" class="small" placeholder="Small" aria-label="Small" />
    <input type="text" placeholder="Default" aria-label="Default" />
    <input type="text" class="large" placeholder="Large" aria-label="Large" />
    <select class="small" aria-label="Small select">
        <option>Small select</option>
        <option>Second option</option>
    </select>
</div>

A switch

A switch is a checkbox with role="switch", so assistive technology announces it as one.

.toggle
    @extend %bf-form-switch
<div class="check">
    <input type="checkbox" role="switch" id="notify" class="toggle" checked />
    <label for="notify">Notifications</label>
</div>

Input groups

Controls, add-on text and buttons join up, sharing their borders. Feedback goes after the group, and shows when a control inside it is invalid.

£
Enter an amount in pounds.
.search
    @extend %bf-input-group

    input
        @extend %bf-form-control

    span
        @extend %bf-input-group-text

    button
        @extend %bf-btn

.search-feedback
    @extend %bf-form-feedback-invalid
<div class="search">
    <span>£</span>
    <input type="number" id="amount" aria-label="Amount" aria-invalid="true" />
    <button type="button">Add</button>
</div>
<div class="search-feedback">Enter an amount in pounds.</div>

Floating labels

Click into the field: the label moves up out of the way. The control comes first, and needs placeholder=" ".

.floating
    @extend %bf-form-floating

    input
        @extend %bf-form-control
<div class="floating">
    <input type="email" id="email" placeholder=" " />
    <label for="email">Email address</label>
</div>

Validation

The first field has aria-invalid="true", as set by a server, so its message shows. Type an invalid address in the second and leave it, and the browser shows its message.

Enter an email address, like name@example.com.
Enter an email address, like name@example.com.
Looks good.
.field
    .error
        @extend %bf-form-feedback-invalid

    .ok
        @extend %bf-form-feedback-valid
<div class="field">
    <input type="email" aria-label="Email" aria-invalid="true" value="not an email" />
    <div class="error">Enter an email address, like name@example.com.</div>
</div>
<div class="field">
    <input type="email" aria-label="Another email" required />
    <div class="error">Enter an email address, like name@example.com.</div>
</div>
<div class="field">
    <input type="email" aria-label="A valid email" value="ben@example.com" />
    <div class="ok">Looks good.</div>
</div>

Select chevron in a dark theme

A select draws its chevron as an image, so a dark theme sets --sassy-select-chevron with chevron(), as well as the text colour.

@use "sassy/src" as sassy

@media (prefers-color-scheme: dark)
    :root
        --sassy-input-colour: #{sassy.colour("grey", 100)}
        --sassy-select-chevron: #{sassy.chevron(sassy.colour("grey", 100))}
