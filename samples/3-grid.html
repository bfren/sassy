Rows and columns

The grid layer, src/3-grid, is a 12-column flex grid: a row extends %bf-d-flex-row, and each column %bf-col-{1-12}, with a breakpoint variant for each width that changes. The full reference is in docs/3-grid.md.

Each demo on this page is styled by sass/3-grid.sass, compiled to css/3-grid.css. Under each demo are its Sass, the CSS that Sassy outputs for it, and its HTML. In the demos, the shaded boxes are each column's content: the white space around them is the gutter.

Two columns that stack on small screens

Side by side from 768px; make the window narrower and they stack.

Left
Right
@use "sassy/src" as sassy

.row
    @extend %bf-d-flex-row

.half
    @extend %bf-col-12
    @extend %bf-col-6-md
<div class="row">
    <div class="half">Left</div>
    <div class="half">Right</div>
</div>

Removing a column's gutter

A utility such as %bf-p-0 always overrides the grid, whatever order the @extend lines are in. The first column has no gutter, so its box reaches the edges.

No gutter
Gutter
Gutter
.third
    @extend %bf-col-4

.edge
    @extend %bf-col-4
    @extend %bf-p-0
<div class="row">
    <div class="edge">No gutter</div>
    <div class="third">Gutter</div>
    <div class="third">Gutter</div>
</div>
