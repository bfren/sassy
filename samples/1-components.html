Buttons, button groups, close buttons, badges, navigation, breadcrumbs, pagination, cards, list groups, accordions, tables, tabs, alerts, progress bars, spinners, skeletons, tooltips, popovers, dropdowns and dialogs

The components layer, src/1-components, styles whole interface elements. Like forms, components are output before the grid and utilities, so a utility can override any part of one. The full reference is in docs/1-components.md.

Each demo on this page is styled by sass/1-components.sass, compiled to css/1-components.css. Under each demo are its Sass, the CSS that Sassy outputs for it, and its HTML. Tabs, toolbars, tooltips, popovers, dropdowns and dismissible alerts also need js/sassy.js.

Accordions

Native <details> elements in a <div>. They share a name, so opening one closes the others, and in browsers that support it they open and close smoothly.

What is an accordion?
A stack of sections, each with a header that opens and closes it.
Does it need a script?
No. Each section is a native <details>, which the browser opens and closes, with the keyboard too.
Why does opening one close the others?
They share name="faq". Leave the name out to let several be open at once.
.accordion
    @extend %bf-accordion
<div class="accordion">
    <details name="faq" open>
        <summary>What is an accordion?</summary>
        <div>A stack of sections, each with a header that opens and closes it.</div>
    </details>
    <details name="faq">
        <summary>Does it need a script?</summary>
        <div>No. Each section is a native <code>&lt;details&gt;</code>, which the browser opens and closes, with the keyboard too.</div>
    </details>
    <details name="faq">
        <summary>Why does opening one close the others?</summary>
        <div>They share <code>name="faq"</code>. Leave the name out to let several be open at once.</div>
    </details>
</div>

Popovers

Click a button. A popover is opened by its button's popovertarget, so the browser opens and closes it, and its links and buttons don't close it. Press Escape or click outside to close one.

Beside the button

Opens after the button, or before it when there is no room.

A popover needs no heading. Give it an aria-label instead.

Dropdowns

Each menu is a popover opened by its button's popovertarget, so the browser opens and closes it. The first two are ARIA menus of actions, reached with the arrow keys; the second is a split button whose menu lines up with its end. The last is a list of links, reached with Tab, that opens above.
