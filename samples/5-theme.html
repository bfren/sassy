5-theme: theme colours and runtime theming

Compiled from sass/5-theme.sass into css/5-theme.css, which this page loads.

Theme colours are custom properties on :root, so a site, a section or a script can change them. The full reference is in docs/5-theme.md.

Dark mode and runtime changes

These need a whole-site or script change, so they are shown here but not applied to this page.

@use "sassy/src" as sassy

:root
    --sassy-theme-primary: #{sassy.colour("sky", 600)}

@media (prefers-color-scheme: dark)
    :root:not([data-theme="light"])
        --sassy-theme-primary: #{sassy.colour("sky", 400)}
        --sassy-select-chevron: #{sassy.chevron(sassy.colour("grey", 100))}
<script>
    document.documentElement.style.setProperty("--sassy-theme-primary", "#0d9488");
</script>
