Theme colours and runtime theming

The theme layer, src/5-theme, names eight colours - primary, secondary, ok, info, warn, error, grey-light and grey-dark - as custom properties, so a site, a section or a script can change them. The full reference is in docs/5-theme.md.

Each demo on this page is styled by sass/5-theme.sass, compiled to css/5-theme.css. Under each demo are its Sass, the CSS that Sassy outputs for it, and its HTML.

Using theme colours

Something went wrong. Please try again.
@use "sassy/src" as sassy

.alert-error
    @extend %bf-bg-error
    @extend %bf-c-grey-50
    @extend %bf-rounded-2
    @extend %bf-p-3
<div class="alert-error">Something went wrong. Please try again.</div>

A section with its own theme

The section sets --sassy-theme-primary, and everything inside it follows - text, and the button component too.

Spring offer: 20% off

.promo
    --sassy-theme-primary: #{sassy.colour("orange", 600)}

.promo-text
    @extend %bf-c-primary
    @extend %bf-font-weight-700

.promo-button
    @extend %bf-btn
    @extend %bf-btn-primary
<section class="promo">
    <p class="promo-text">Spring offer: 20% off</p>
    <button type="button" class="promo-button">Shop now</button>
</section>

Changing the theme at runtime

Choose a colour: a script sets --sassy-theme-primary on this demo, and its button and link follow, with no new stylesheet.

A primary link

.themed-button
    @extend %bf-btn
    @extend %bf-btn-primary

.themed-link
    @extend %bf-c-primary
    @extend %bf-font-weight-700

.choices
    @extend %bf-d-flex
    @extend %bf-flex-wrap-wrap
    @extend %bf-gap-2

.choice
    @extend %bf-btn
    @extend %bf-btn-small
<script>
    element.style.setProperty("--sassy-theme-primary", "#0d9488");
</script>

Dark mode

A media query changes the theme for readers who prefer dark colours. It needs a whole-site change, so it is not applied to this page.

@use "sassy/src" as sassy

@media (prefers-color-scheme: dark)
    :root:not([data-theme="light"])
        --sassy-theme-primary: #{sassy.colour("sky", 400)}
        --sassy-body-colour: #{sassy.colour("grey", 100)}
        --sassy-btn-bg: #{sassy.colour("grey", 800)}
        --sassy-input-bg: #{sassy.colour("grey", 800)}
        --sassy-select-chevron: #{sassy.chevron(sassy.colour("grey", 100))}
