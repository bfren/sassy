2-components: navigation, cards, tabs, tooltips and dialogs

Compiled from sass/2-components.sass into css/2-components.css, which this page loads. Tabs and tooltips also need js/sassy.js.

Components are groups of styles that make up a whole interface element. Like forms, they are output before the grid and utilities, so a utility can override any part of one. The full reference is in docs/2-components.md.

Navigation

A list of links. Mark the current page with aria-current="page", which also tells screen readers.

  • Home
  • About
  • Contact
@use "sassy/src" as sassy

    @extend %bf-nav

        <li><a href="#about">About</a></li>
        <li><a href="#contact">Contact</a></li>
    </ul>
</nav>

Tooltips

Hover over or tab to a button. A tooltip is a popover described by its trigger with aria-describedby, and anchor positioning places it above the trigger, or below if there is no room.

Saves your changes to this device
Copies a link you can send to someone
.tip
    @extend %bf-tooltip
<div class="buttons">
    <button type="button" class="button" aria-describedby="tip-save">Save</button>
    <button type="button" class="button" aria-describedby="tip-share">Share</button>
</div>
<div class="tip" role="tooltip" popover="manual" id="tip-save">Saves your changes to this device</div>
<div class="tip" role="tooltip" popover="manual" id="tip-share">Copies a link you can send to someone</div>

Dialogs

The buttons open and close the dialog with command and commandfor, so no script is needed in current browsers. sassy.js adds the same behaviour to older ones.
