Buttons, navigation, cards, tabs, tooltips and dialogs

The components layer, src/2-components, styles whole interface elements. Like forms, components are output before the grid and utilities, so a utility can override any part of one. The full reference is in docs/2-components.md.

Each demo on this page is styled by sass/2-components.sass, compiled to css/2-components.css. Under each demo are its Sass, the CSS that Sassy outputs for it, and its HTML. Tabs and tooltips also need js/sassy.js.

Buttons

A theme colour, the outline style and the sizes only change custom properties, so extend them as well as %bf-btn.

Navigation

Mark the current page with aria-current="page", which also tells screen readers. The navigation at the top of this page is the underline style.

  • Home
  • About
  • Contact
.menu
    @extend %bf-nav

    a
        @extend %bf-nav-link
<nav aria-label="Example">
    <ul class="menu">
        <li><a href="#nav" aria-current="page">Home</a></li>
        <li><a href="#nav">About</a></li>
        <li><a href="#nav">Contact</a></li>
    </ul>
</nav>

Tooltips

Hover over or tab to a button. A tooltip is a popover, described by its trigger with aria-describedby.

Saves your changes to this device
Copies a link you can send to someone
.tip
    @extend %bf-tooltip
<div class="buttons">
    <button type="button" class="button" aria-describedby="tip-save">Save</button>
    <button type="button" class="button" aria-describedby="tip-share">Share</button>
</div>
<div class="tip" role="tooltip" popover="manual" id="tip-save">Saves your changes to this device</div>
<div class="tip" role="tooltip" popover="manual" id="tip-share">Copies a link you can send to someone</div>
